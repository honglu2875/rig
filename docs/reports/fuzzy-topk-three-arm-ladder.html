Fuzzy competition works. Sparsifying its input does not.

The result

The outer approximation is the useful intervention

At each completed tier, the fuzzy arm stores a 16D dictionary and retains one ReLU winner from each fixed group of four, giving K=4D. Against the dense 4D GELU control, its paired mean improvements are 0.078033 nats at 60M, 0.069399 at 125M, and 0.076030 at 250M. Every seed agrees on direction.

The double-fuzzy arm additionally keeps one signed coordinate from each group of four before UP. It stores more parameters and is matched on the same total active matrix-FLOP axis, yet it is worse than fuzzy by 0.076437 nats at 60M and 0.062993 at 125M. It lands close to dense rather than improving on fuzzy.

What changed

One selector helps; the second changes the information path

Fuzzy TopK

z = x_norm W_up + b_up (a, i) = GroupedTopK(ReLU(z), group_size=4) y = Σ a[j] W_down[i[j], :] + b_down

The fixed groups approximate global TopK without a large sort or a loop over K. Each stored feature retains its own decoder row. The model scores all H=16D features, then keeps K=4D.

Double-fuzzy TopK

(v, r) = GroupedSignedMax(x_norm, group_size=4) z = Σ v[q] W_up[r[q], :] + b_up (a, i) = GroupedTopK(ReLU(z), group_size=4) y = Σ a[j] W_down[i[j], :] + b_down

The added inner selector exposes only Q=D/4 normalized coordinates to the learned MLP update. It ranks signed values, not magnitudes, and does not apply an inner ReLU.

The residual stream is not discarded. These are pre-norm blocks: the full block input is saved as the residual bypass, while only x_norm entering the MLP branch is grouped. The block returns the unchanged bypass plus the selected MLP update. The negative result is therefore about the update's restricted readout, not loss of the identity path.

Systems result

The approximation removes the catastrophic TopK path, but not all overhead

The original exact global TopK coordinate sustained only 22.53K tokens/s at the 60M timing gate, about 59× slower than dense. The fixed-group choicewise fuzzy kernel reached 966.06K tokens/s in that gate and 1.109M tokens/s averaged over the three complete 60M runs. It is a viable quality experiment, though still slower than dense because regular contractions execute more matrix work.
