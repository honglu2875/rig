Reconstruction revives features.
The coefficient pays the bill.

A discarded training-only decoder can keep far more of a 16D fuzzy dictionary active, but the effect is nonlinear and eventually trades against language-model loss. The useful result is a frontier: β=¼ preserves the fuzzy model's quality while cutting cadence-matched persistent inactivity by 35%. Literal residual AuxK adds nothing.

The dose response is a frontier, not a monotone win.

Three paired seeds at the original five-dense-TPP deployed active-compute coordinate. Error statements use same-seed loss differences; survival means zero positive activation at both exact shared captures, steps 4,600 and 4,656.

The two weak doses are not intermediate mechanistically. β=1/64 and β=1/16 finish with 40.49% and 38.37% aligned inactivity—worse than β=0. The decoder's private Adam state also means scaling its raw gradient does not linearly scale its update. The measured frontier should not be interpolated as if β were a simple regularization temperature.

What the intervention and archive contain

The deployed path never reads the auxiliary decoder. The archive separates lossless evidence from browser-friendly reductions.

Gradient contract. Selected hidden values and identities decode the stopped RMS-normalized MLP input through a separate unit-row matrix. Reconstruction gradients reach W_up, b_up, and the train-only decoder; they are blocked from the residual input and deployed W_down. The decoder is stripped from deployment checkpoints.

Compute contract. All short sparse arms use 226.75M deployment parameters and 72.09M train-only parameters. Reconstruction raises physical MLP matrix work from 12MDH to 18MDH; literal AuxK raises it to 19MDH. Active deployed compute, not wall time or optimized parameter count, is the ladder coordinate.

Raw evidence. Nineteen runs retain fuzzy_sparsity.rigvec, totaling 4.16 GB. Parent controls record at cadence 10; treatments record at cadence 100. Every recorded layer × feature vector is preserved. The complete 23-run study payload is about 4.60 GB.

Browser policy. The landing snapshot is 0.37 MB. The explicitly loaded expanded report is 5.52 MB, bounded to 2,048 points per run-series and 32 layer frames. Its neuron explorer uses a widening-step lossy companion. Raw .riglog and .rigvec files remain authoritative.

AuxK boundary. Literal AuxK reconstructs the stopped residual error using selected dead features after 10M inactive tokens. Its β=1 three-seed result is negative. This rejects the tested coefficient/selector, not every possible dead-feature auxiliary target.

Evidence boundary. All short claims are 125M on one v4-32 topology. The hero is one held-out seed. There is no 20-TPP fuzzy-only control, so neither the late curve nor the endpoint isolates reconstruction from the already-strong fuzzy architecture.
