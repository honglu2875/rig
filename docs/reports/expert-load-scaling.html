02 · mechanism

The diagnostics distinguish “scale gradients” from “scale learning rate.”

Busy experts carry about 1.9× the raw-gradient RMS of idle experts in every arm. What differs is whether that imbalance survives Adam normalization.

Gradient mode

The factor is applied after global clipping and before both Adam moments. Stable scaling divides out; only changes in load can create a transient.

Update mode

The factor multiplies normalized Adam plus decoupled decay. It is a literal per-expert learning-rate multiplier and remains visible in every update.

Expert symmetry

Ordinals are tracked only within a run. Cross-treatment summaries use busiest/idlest roles and within-layer correlations, which survive expert relabeling.

Working decision

Do not adopt either rule. Gradient c=0.5 is harmless but functionally neutral; stronger gradient scaling offers no gain. Direct update scaling successfully creates load-proportional steps and worsens validation. Preserve the branch and diagnostics as a negative result; revisit only with a materially different rule, not a larger reseed of this exact sweep.
